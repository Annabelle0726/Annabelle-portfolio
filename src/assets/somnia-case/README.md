# Somnia case assets

- `home.webp`: supplied Somnia homepage screenshot, resized from e0ad47872b4ffea5f0aa1761162aa889.png.
- `library.webp`: supplied c682a7d9505e072504cdddd78a8d42fb.jpg; browser toolbar removed and resized.
- `match.webp`: crop of the matching-preview artwork already displayed in the supplied homepage screenshot. The case labels it as a homepage preview rather than a separately verified interactive screen.
- `ribbon.webp`: generated transparent blue/white/champagne-gold silk decorative image, optimized to WebP. Animation is CSS-based with pointer response, manual pause, and reduced-motion support.
- `interaction.mp4`: local web derivative of the user's `Agency 2026-10-17 20-25-18.mp4` (10-second desktop interaction recording). Cropped browser chrome and capture edges, resized to 1600px wide, H.264 with fast-start metadata, silent. The source recording is unchanged.
- `interaction.jpg`: poster extracted at 1 second using the same crop as the recording.

The B case layout uses Welcome as its hero and the recording for interaction details. The user excluded the Across Screens section and requested the original project-navigation and return-to-top controls. Welcome capture artifacts are hidden by matching CSS display frames in thumbnails and dialogs; the source image remains unchanged.

Source product: Somnia Library, an adaptation of Greg Chism's Reverie. The screenshots retain the product's own visual identity; the case page uses the portfolio's shared theme and SectionHeader signature.
