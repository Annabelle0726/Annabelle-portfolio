# Sidebar Implementation Plan

**Goal:** Refine the accepted sidebar direction, its SVGs, bilingual navigation, typography and social-account access without rewriting main or secondary content.

**Architecture:** A separate Sidebar component owns navigation groups and account dialogs. App owns the saved navigation language and mobile drawer. Scoped sidebar CSS keeps the existing 300px desktop shell and all content typography intact.

**Tech Stack:** Existing React/Vite, native SVG and dialog, locally served fonts and account images. No additional runtime library.

**Spec:** User-approved work-first sketch and follow-up scope of 2026-10-29. Side profile: name/socials left, smaller portrait right. Five groups: Home, Projects, WeChat, Favorites, Contact & résumé. Chinese first; content remains unchanged.

## Constraints and visual decisions
- Preserve every file under src/sections and the Hero markup.
- Retain blue/yellow identity. Navigation SVGs use a 24-unit grid, 1.6-unit round navy strokes, restrained yellow secondary fills. Use actual platform vectors for social marks.
- Oil-icon construction principles apply; its own scope recommends vectors for dense functional UI, so no generated raster substitutes.
- Brand font: Outfit for the name and Latin navigation, Noto Sans SC for Chinese; local files with system fallbacks. Name about 20px, navigation 15–16px, children 14px, comfortable line height and content-sized rows.
- Existing section anchors stay intact. Favorites children are visibly forthcoming until the user supplies content; no fake destination pages.
- User-supplied QR cards remain unaltered files. Display a CSS viewport around the QR with quiet space, preserve access to original, copy actual account name/ID. Only use a decoded URL as a link.

## Review focus
- Long English labels or 200% text must wrap, never cover the avatar or arrow.
- Drawer focus must stay inside while open, return to opener, and survive resize.
- Escape closes the account dialog before closing the mobile menu.
- Saved-language storage unavailable: navigation still loads in Chinese.
- Original section content, resume download and existing project links remain unchanged.

## Delivered assets and maintenance
- Navigation illustrations are original inline SVGs in `SidebarIcon.jsx`. Social marks use [Bootstrap Icons 1.11.3](https://github.com/twbs/icons/tree/v1.11.3) and the Xiaohongshu mark from [Simple Icons 14.0.0](https://github.com/simple-icons/simple-icons/tree/14.0.0). Their license files are stored beside the SVG assets.
- Local variable fonts are [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit) and [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc), with OFL license files beside the fonts. The Chinese file is subset to the current sidebar/account labels. When adding Chinese labels, refresh the subset; system Chinese fonts cover characters outside it. Main typography is unchanged.
- Both user-supplied QR JPEGs are stored unchanged in `src/assets/social`. The display uses CSS viewports; the original remains downloadable. URLs were decoded from the provided files, not constructed from a display ID. WeChat copies the displayed account name; Rednote copies `315247955`.
- No runtime dependencies were added. Sidebar CSS is scoped to its components, account dialogs and top controls.
