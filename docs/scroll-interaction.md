# Shared scrolling and navigation interaction

- `src/scrollbars.css` styles the document scrollbar (the main content's actual scrolling surface), fixed sidebar and account dialog. Desktop WebKit-compatible styling uses a 5px track and short diamond-shaped tips. Overlapping gradient layers and a small antialias band soften the tip edges and prevent seams. Firefox uses its native thin scrollbar fallback.
- Geometry and colors live in `src/theme.css` as `--scrollbar-*` variables. Hover and drag states derive from the existing blue palette. Stable desktop gutters avoid sideways shifts between short and long views.
- Coarse-pointer devices keep native overlay indicators. Scrolling remains browser-native, with no wheel interception or custom touch physics. Sidebar/dialog overscroll containment prevents chaining into the underlying view; document overscroll does not trigger app-level refresh.
- Menu children use a short CSS grid expansion transition. Collapsed panels become `inert` and `aria-hidden` immediately; the mobile focus trap excludes them. Link press feedback is immediate, pointer hover is capability-gated, and reduced-motion preferences remove the transitions. Selection text remains copyable in content, while control labels suppress long-press selection.
- Validation: production build and navigation unit checks; desktop wheel scrolling and sidebar boundary isolation; direct primary and secondary links; native coarse-pointer scrollbar branch; mobile focus trap, destination focus and Escape; reduced-motion branch. Desktop screenshots are under ignored `.oil-ui/scroll-polish/`.
- Browser emulation cannot verify physical-phone inertia, Safari rubber-banding, notch behavior or tactile feel. Those remain unverified on hardware. Scrollbar thumb dragging remains native browser behavior; it was not confirmed by the automated pointer check.
